# Research Figures

This directory contains visualisations generated by the IL&FS index-options event study.

Figures cover event-study comparisons, option Greeks, implied volatility, Black–Scholes pricing performance, and delta-hedging effectiveness.

Each figure should be interpreted alongside the methodology, sample period, and limitations documented in the main project README.

Source data: NSE historical market data, subject to applicable data-use and redistribution terms.
