# Research Tables

This directory contains summary tables produced by the IL&FS index-options event study.

The tables cover descriptive statistics, dataset validation, correlation analysis, event-study summaries, regression results, pricing performance, statistical tests, and hedging performance.

Refer to the main project README for the study design, event date, and interpretation of the results.

Source data: NSE historical market data, subject to applicable data-use and redistribution terms.
